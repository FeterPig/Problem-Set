# C++ 代码规范

编写或修改任何 C++ 代码时，必须遵守以下规范：

1. **万能头文件**：必须使用 `#include <bits/stdc++.h>`，不得使用其他标准库头文件。
2. **大括号**：即使循环体（`for`、`while`）或条件体（`if`、`else`）内只有单行语句，也必须加花括号 `{ }`。
3. **return 0 前空行**：在 `main` 函数的 `return 0;` 之前，必须保留一个空行。
